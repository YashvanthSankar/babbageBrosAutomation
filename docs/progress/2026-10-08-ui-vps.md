## VPS deployment

1. Point a DNS hostname at the VPS and allow inbound TCP 80/443.
2. Install Docker with Compose on the VPS; clone this repository there.
3. Create ignored `.env.production` with `NEXTAUTH_URL=https://YOUR_DOMAIN`, `NEXTAUTH_SECRET`, `PROFESSOR_EMAIL`, the production Convex URL and matching `CONVEX_BACKEND_SECRET`, plus configured email/voice/Google provider variables from `.env.example`. Store values only on the host.
4. Start with `APP_DOMAIN=YOUR_DOMAIN docker compose --env-file .env.production up --build -d`. Caddy obtains HTTPS automatically. The Compose env file provides the Convex public URL to the build as well as the container runtime.
5. Check `https://YOUR_DOMAIN/api/health` and test professor sign-in → add subject → roster import → attendance/marks → student dashboard → booking.

Production Convex URL/secret and VPS hostname/SSH login/public domain must be supplied or located before deployment. No guessed server was used and no live notifications were sent by this UI task.
